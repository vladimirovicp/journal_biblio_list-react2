# Документация проекта Journal Biblio List

**Дата:** 06.05.2026  
**Версия:** 0.0.0 (каркас)

---

## 1. Обзор проекта

**journal-biblio-list-react2** — фронтенд-приложение для генерации библиографического списка журнала и последующей работы с XML.

Проект находится на стадии каркаса: базовая архитектура собрана, UI-композиция работает, но основная бизнес-логика (форма ввода, генерация XML, скачивание файлов, интеграция с API) представлена заготовками.

## 4. Компоненты

### 4.1. App (`src/App.tsx`)

Корневой компонент. Рендерит `MainLayout`, внутрь которого помещает `GeneratorFeature`.

```tsx
<MainLayout>
  <GeneratorFeature />
</MainLayout>
```

### 4.2. Layout-компоненты

#### MainLayout (`src/components/layout/MainLayout.tsx`)

Обёртка на базе `antd/Layout`. Принимает `children: ReactNode` и рендерит структуру:

```
Layout
├── Header
├── Layout.Content → children
└── Footer
```

Контент ограничен максимальной шириной `1200px` и центрирован.

#### Header (`src/components/layout/Header.tsx`)

Шапка с заголовком **"Journal Biblio List"**. Использует `Layout.Header` из antd.

#### Footer (`src/components/layout/Footer.tsx`)

Подвал с текстом **"Journal Biblio List"**. Использует `Layout.Footer` из antd.

### 4.3. Фича генератора

#### GeneratorFeature (`src/features/generator/index.tsx`)

Контейнерный компонент фичи. Управляет состоянием `selectedSiteUrl: string | null` и передаёт его дочерним секциям:

```text
GeneratorFeature (state: selectedSiteUrl)
├── SiteSelectorSection  — выбор URL, вызывает onChange
├── FormStep             — форма, блокируется пока URL не выбран
└── XmlPreview           — предпросмотр, отображает выбранный URL
```

#### SiteSelectorSection (`src/features/generator/components/SiteSelectorSection.tsx`)

Секция выбора сайта. Принимает `value` и `onChange`, рендерит `CustomSelect` с опциями из `SITE_OPTIONS`.

**Props:**

| Prop      | Тип                      | Описание                        |
|-----------|--------------------------|---------------------------------|
| `value`   | `string \| null`         | Текущий выбранный URL           |
| `onChange`| `(url: string \| null)`  | Callback при выборе URL         |

#### FormStep (`src/features/generator/FormStep.tsx`)

Секция формы обработки. Пока URL не выбран, отображается `Alert` с сообщением о блокировке, форма находится в состоянии `disabled`. После выбора URL отображает поле с выбранным сайтом и placeholder для будущих полей.

**Props:**

| Prop             | Тип               | Описание                |
|------------------|-------------------|-------------------------|
| `selectedSiteUrl`| `string \| null`  | Выбранный URL сайта     |

#### XmlPreview (`src/features/generator/XmlPreview.tsx`)

Секция предпросмотра XML. Если URL выбран — отображает его в styled-бадже. Иначе — placeholder-текст.

**Props:**

| Prop             | Тип               | Описание                |
|------------------|-------------------|-------------------------|
| `selectedSiteUrl`| `string \| null`  | Выбранный URL сайта     |

### 4.4. UI-обёртки

#### CustomButton (`src/components/ui/CustomButton.tsx`)

Тонкая обёртка над `antd.Button`. Принимает все стандартные `ButtonProps` и прокидывает их без изменений. Предназначена для централизованной кастомизации кнопок в будущем.

#### CustomSelect (`src/components/ui/CustomSelect.tsx`)

Generic-обёртка над `antd.Select`. Параметризуется типом значения `ValueType`:

```tsx
CustomSelect<string>  // select со строковыми значениями
```

Принимает все стандартные `SelectProps<ValueType>`. Предназначена для централизованной кастомизации селектов.

## 5. API-слой

### client (`src/api/client.ts`)

Экземпляр `axios.create()` с `baseURL`, который берётся из переменной окружения `VITE_API_BASE_URL`. Если переменная не задана — используется `/`.

Подключены пассивные interceptors для запросов и ответов (передают config/response без изменений, прокидывают ошибки).

### endpoints (`src/api/endpoints.ts`)

Пустой объект `API_ENDPOINTS`. Заготовка для хранения констант маршрутов API.

### types (`src/api/types.ts`)

```typescript
interface ApiResponse<T = unknown> {
  data: T
}
```

Базовый тип для обёртки ответов API.

## 6. Утилиты и хуки

### xmlBuilder (`src/utils/xmlBuilder.ts`)

Функция `buildXmlTemplate(): string` — заготовка. Возвращает пустую строку. Предназначена для генерации XML-документа на основе данных формы.

### fileHelper (`src/utils/fileHelper.ts`)

Функция `downloadPlaceholderFile(): void` — заготовка. Предназначена для скачивания сгенерированного файла.

### useDebounce (`src/hooks/useDebounce.ts`)

Хук `useDebounce<T>(value: T): T` — заготовка. Возвращает значение без задержки. Предназначен для отложенной обработки ввода (например, при поиске или вводе URL).

## 9. Состояние и поток данных

Приложение использует управляемое состояние на уровне фичи (без глобального стейт-менеджера).

```text
                          GeneratorFeature
                     (useState: selectedSiteUrl)
                               │
          ┌────────────────────┼────────────────────┐
          │                    │                     │
  SiteSelectorSection     FormStep              XmlPreview
   value, onChange       selectedSiteUrl       selectedSiteUrl
          │
          │ onChange(url)
          └──→ setSelectedSiteUrl(url)
```

1. Пользователь выбирает URL в `SiteSelectorSection` через `CustomSelect`.
2. `GeneratorFeature` обновляет `selectedSiteUrl` через `useState`.
3. Обновлённое значение прокидывается в `FormStep` и `XmlPreview`.
4. `FormStep` активируется (снимается `disabled`), `XmlPreview` отображает URL.
